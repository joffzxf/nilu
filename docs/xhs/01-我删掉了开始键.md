# 我删掉了开始键

做这个游戏之前，我先做了一个 60 秒的版本。

60 秒到了，光点停下，屏幕出现分数。我发现自己一点也不难过。因为可以重开。
重开太容易了，死亡就像一次暂停。

后来我把「开始」删了。
打开页面，光点已经在了。
没有教程，没有说明，没有「点击开始」。
它就在屏幕正中央，一秒老一秒。
右上角的数字慢慢变大，那是它走过的面积。

我又把时间改成了现实时间。
关掉网页，它不会停。
你隔很久再打开，它已经往前走了很远。

底部有一条年龄轴，贴着面积的底边。
起点钉在页面最左边，0 不写出来。
刻度越来越密，像时间在往光点脚下挤。
只有光点正下方，一个年龄数字在轻轻跳。

快进。
人可以跳过等待，直接去看结果。
但快进不会让你更努力，它只是把现在的高度，乘以更多时间。
你努力过，快进会放大它；
你没努力，快进只是让你更快到终点。

努力。
第一次要按十个方向键，之后每成功一次多一个，没有上限。
没有倒计时，但必须按对。
按错，重新点「努力」，从头再来。
我不想把努力做成反应测试。
努力更像是在某个下午，决定认真做一件事。

结束。
点下去之前会问一次：结束即注销，不能再回来。
确认之后，光点缩小，轨迹淡出，屏幕变黑。
不能在这个页面重开，只能关掉网页。

这是正式版第一版。
它不问你这一生有没有意义。
它只把你花掉的时间和抬过的头，画成一条线，
然后让线下面的数字一直涨。

三万天。
一个光点。
没有开始键。
