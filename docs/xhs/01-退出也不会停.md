# 退出也不会停

我把上一版游戏的 60 秒删掉了。

现在，打开页面，光点就出生。
它一直在屏幕正中央。现实一秒，它就老一秒。
右上角的数字，是它走过的面积。
页面上只有三个动作：快进、努力、结束。

游戏一定要有开始和重来吗？
后来发现，正是这两个东西让死亡变得很假。
这一版没有开始按钮，也没有重来。
你关掉网页，它不会停。

【快进】
是我最犹豫的一个功能。
人可以跳过时间吗？可以。
但快进不增加斜率，它只是把你现在的高度乘以更多的时间。
你努力过，快进会把那点努力放大；
你没努力，快进只是让你更快到终点。
到了三万天，这一生就结束，账号注销。
我保留它，是因为我不想假装人不会想逃。

测试的时候，我把快进拖到第 15000 天。
数字一下子大了很多。
我盯着它看了很久，发现我并没有更努力，
只是把时间提前花掉了。

【努力】
没有倒计时，但必须按对。
第一次就是十个箭头，之后每成功一次多一个。
按错，重新点「努力」，从头再来。
我不想把努力做成反应测试。

【结束】
点下去之前会问你一次：结束即注销，不能再回来。
确认之后，光点缩小，轨迹淡出，屏幕变黑。
不能在这个页面重开，只能关掉网页。

做这个游戏的时候我一直在想：
如果关掉网页它也不停，
那到底是我在玩游戏，还是游戏在看着我？

那个数字后来会变得很大，大到读不懂。
可它变大，主要不是因为努力，
是因为时间一直在走。

三万天。
一个光点。
你只有一次。

如果关掉网页它也不会停，你还敢开始吗？
