# 所有走过的人，都在榜上

第一版做完，有人问我：成绩给谁看？

于是第二版，我给它接上了 GitHub 账号。
不用注册，不用密码，不读邮箱，只拿公开的用户名和头像。

但真正麻烦的不是登录，是「分数谁说了算」。

如果分数由前端算，等于让考生自己批卷。
所以现在是这样：
服务器发一个随机种子 → 前端用它生成这一局的指令 → 玩家敲键，记录每个按键发生在第几帧 → 结束后把输入日志交回服务器 → 服务器用同一套规则重新跑一遍，算出面积。

前端传来的分数，我一个都不信。

还有几个小决定：
· 排行榜不只看前 50，所有登录过的账户都在榜上，包括 0 分和还没走出第一步的人。
· 榜不是「赢家榜」，更像一份「同行者名单」。
· 每个账户只取最好的一局；周榜每周一重新开始。

踩坑：
跨站 Cookie 被浏览器拦得七零八落，最后改成一次性登录码 + Bearer token。
浏览器不让你随便带 Cookie，那就不带。

现在测试服里有 5 个假账号，最高 10,182。
别当真，他们都是我写的脚本。
真实的人能走多远，要等你们来告诉我。

下一版：把 API 部署上线，让榜是真的。
