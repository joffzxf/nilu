## 评论区

评论区不放外部链接。小红书评论不支持把外链藏在一段文字后面，硬贴域名只会显示完整地址，或被折叠、限流。

只保留一句引导，让链接留在正文里：

> 试玩入口在正文最后一行。

如果想让人在评论区互动，可以改成「想试玩的扣『逆旅』，我发你」，再用私信把地址发过去。这个更花时间，但评论区不会出现链接。

不要用短链伪装、零宽字符、二维码图片或「点我」之类的假超链接；平台识别到站外导流会限流，严重的会封号。
