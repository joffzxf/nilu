## 账号语气

- 第一人称，独立开发者。
- 不卖课、不喊「重磅」、不写「全网首个」。
- 可以写失败、写改坏的东西、写不确定。
- 技术细节只保留「能让人听懂」的部分：种子、回放、一次性凭证、跨站 Cookie。
- 每篇结尾留一个真问题，不是「点赞关注」，而是「你会怎么走」。
