# 我做了个不能回头的游戏

「人生如逆旅，我亦是行人。」

我把这句话，做成了一个只能向右走的光点。

它叫《逆旅》。
六十秒，一条路。按顺序敲下方向键，每完成一组，光点的斜率就抬高一点。指令会越来越长，给键的时间越来越短。
六十秒后，轨迹下的面积，就是成绩。

为什么是面积，不是最高分？
因为最高分只记录一个瞬间。
面积记录的是：你抬着头，走了多久。

为什么失误不扣高度？
因为光点不能回头，但也不该因为一次踏空，就否定已经走过的路。
失误的代价是时间：这一组作废，喘息，下一组重来。
结算页会写：「高度没有丢，只是少走了一段。」

第一版没有账号，没有排行榜，甚至没有后端。
我先让光点走起来。

做的过程中改了一次难度：原本失误后下一组还是那么长，手慢的人会陷入「超时 → 更长 → 再超时」的死循环。
后来加了「喘息」：连续失误后，下一组会变短、窗口会变宽。
游戏可以难，但不能让人无事可做。

现在 demo 在 GitHub Pages 上，打开就能走。
没有登录，成绩只留在这台设备。
下一版，想让它记住每一个走过的人。

你会想走一程吗？
