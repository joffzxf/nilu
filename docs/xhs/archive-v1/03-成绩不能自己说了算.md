# 成绩不能自己说了算

「前端算分，等于把答案交给考生自己批。」
这句话我贴在显示器上，做了第三版。

第三版没有加新玩法，只做了一件事：让成绩可信。

流程变成：
1. 服务器发一局凭证：种子、时长、引擎版本、过期时间。
2. 前端本地模拟，玩家只负责敲键。
3. 输入日志必须严格递增——同一帧按七个键，直接拒绝。
4. 服务器用同一份确定性引擎重放，重新算面积。
5. 凭证一次性使用，15 分钟过期，一人同时只有一局。

能防什么？
改前端分数、改 localStorage、自选种子、重放旧请求、提交别人的局、一秒七键。

防不住什么？
脚本可以生成完美输入。
回放只能证明「这份输入确实得到这个分数」，不能证明「输入来自人类」。
所以我不敢写「绝对防作弊」。

架构也做了减法：
· 前端纯静态，GitHub Pages 托管，后端挂了也能玩。
· API 用 Cloudflare Worker + D1，没有常驻服务器。
· 没有 WebSocket，没有 Redis，没有 JWT；随机 token + 数据库哈希，够用。
· 网络失败时，这一局先存本机，下次打开自动补交。

可靠不是堆技术。
是把「谁说了算」分清：
前端记录发生了什么，
服务器计算这值多少分，
静态页面保证你随时能打开。

完整架构和部署步骤我写在仓库里了。
下一步想做的事：冻结旧引擎版本，让历史成绩永远可回放；
以及，给前排加一点人类节奏的校验。
